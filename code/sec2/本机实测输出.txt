########## 实验 3：反序列化过滤器进阶 ##########
=== 1) 先看几个字符串模式解析成什么（不装到进程上）===
    模式 java.base/*;!*
        → 解析出的过滤器 = java.base/*;!*
    模式 !SecFilterAdv$Node;java.base/*;!*
        → 解析出的过滤器 = !SecFilterAdv$Node;java.base/*;!*
    模式 maxdepth=3;*
        → 解析出的过滤器 = maxdepth=3;*
    模式 maxrefs=2;*
        → 解析出的过滤器 = maxrefs=2;*
    模式 maxarray=4;*
        → 解析出的过滤器 = maxarray=4;*
    模式 [Ljava.lang.String;;java.base/*;!*
        → 解析出的过滤器 = [Ljava.lang.String;;java.base/*;!*
    模式 [I;java.base/*;!*
        → 解析出的过滤器 = [I;java.base/*;!*

=== 2) maxdepth：拦的是「嵌套多深」，不是「哪个类」===
    链长 2（字节数 86） —— 过滤器 [maxdepth=4;*] → 读成功（Node）
    链长 6（字节数 126） —— 过滤器 [maxdepth=4;*] → 拦下：InvalidClassException: filter status: REJECTED

=== 3) maxrefs：拦的是「一次读里有多少个引用」===
    List 里 30 个 Pair（字节数 640） —— 过滤器 [maxrefs=8;java.base/*;*] → 拦下：InvalidClassException: filter status: REJECTED

=== 4) 数组模式与 maxarray ===
    String[20] 的数组 —— 过滤器 [maxarray=8;java.base/*;*] → 拦下：InvalidClassException: filter status: REJECTED
    String[20] 的数组（显式拒绝数组模式） —— 过滤器 [![Ljava.lang.String;;java.base/*;!*] → 读成功（String[]）

=== 5) 进程级过滤器只能设一次 ===
    第一次 setSerialFilter：成功
    第二次 setSerialFilter 抛：java.lang.IllegalStateException: Serial filter can only be set once
    现在进程级过滤器 = java.base/*;!*

=== 6) 进程级过滤器设上之后，流级还能不能覆盖它 ===
