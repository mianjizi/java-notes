# Java 自学教程

一套从零开始的 Java 自学材料，**14 篇 / 约 5600 行**，含 3 张自制图表，以及**可重跑的探针与安全靶场代码**（纯 JDK，不需要 Maven/Gradle）。

内容特点是：**凡是「本机行为」的结论，都在一台真实的机器上跑过一遍再写** —— 版本号、报错原文、编码与命令行开关的实际效果、反序列化钩子的调用次数、字节码改写前后的字节数、JVM 自己打出的告警文本。笔记里每一处引用日志的地方都逐字对应 `code/*/本机实测输出.txt` 里的原文，可以自己去核。

看 **[00-Java索引](00-Java索引.md)** —— 里面有学习地图、每篇的时间预算、本机环境实测数据、学习纪律与进度表。

## 关于安全专题（请先读这一段）

- 这四篇的定位是**从网络安全人员的视角理解 Java**，属于学习材料，不是工具。
- 全部实验只用本机 JDK，靶子都是**自己写的无害程序**，只绑 `127.0.0.1`；**仓库里不含任何可用于攻击他人系统的载荷、利用链或绕过技巧**。
- 涉及反序列化的部分只演示「读对象时会执行什么代码」这一机制，以及官方过滤器怎么拦；涉及 JNDI 的部分只演示本机被拒绝的过程。
- 12 篇里引用的 CVE 编号、CVSS、ATT&CK 技术编号与 CWE 名称都逐一联网核对过，并在正文里写出核对来源与核对日期。
- 法律边界只引条文号（《刑法》第 285、286 条；法释〔2011〕19 号），并声明：**这是边界说明，不是法律意见**。
- 请在**你自己的机器、你自己的程序**范围内做这些实验。

## 环境

- JDK：Eclipse Temurin **25**（LTS），Windows 11，脚本在 git-bash 下跑。
- 不依赖 Maven / Gradle，也不下载第三方库；所有探针与靶场只用 JDK 自带的东西。
- `code/sec2` 里的运行期附加实验需要 `jdk.attach` 模块（标准 JDK 自带）。

## 怎么继续更新

```bash

# 3) 重跑探针与靶场，日志按批次追加，正文引用要与日志逐字对得上
cd code/probe && bash run.sh
cd code/sec2 && bash run.sh
```
